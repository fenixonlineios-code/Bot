Conexão

Supabase

Cole a URL e a chave anônima (anon key) do seu projeto. Depois de rodar o SQL abaixo, use "Testar conexão" — se algo estiver errado, o erro exato do Supabase aparece aqui.

Depois de criar a primeira conta admin, troque o código de convite (tabela admin_convites) e, para segurança extra, desative cadastros públicos em Authentication → Settings no painel do Supabase — assim ninguém cria conta sem passar por você.

Pagamentos

Selo Premium com Stripe

Crie um Payment Link gratuitamente no painel do Stripe (Dashboard → Payment Links) e cole a URL abaixo. Essas configurações ficam salvas no Supabase e valem para todos os visitantes do site — não só para o seu navegador.

Stripe não configurado

Nota honesta: confirmar pagamento automaticamente exige um backend recebendo o webhook do Stripe. Sem servidor próprio, isso ainda é possível 100% dentro do Supabase usando uma Edge Function — o SQL acima já deixa a tabela pronta para isso. Enquanto isso não estiver configurado, confirme os pagamentos manualmente aqui na tabela (botão 💳) conferindo no seu painel do Stripe.
